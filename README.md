# Estudos de Sistemas Web

Repositório usado para desenvolver as atividades da disciplina CC6PDSW - Projeto e Desenvolvimento de Sistemas Web.

## Atividades

- `atividade-interface`: páginas desenvolvidas com CSS tradicional e Tailwind CSS.
- `tarefa-javascript`: exercício básico de JavaScript.
- `tarefa-react`: aplicação React com TypeScript, componentes reutilizáveis e três páginas.
- `tarefa-contador`: contador em React com botões de incrementar, decrementar e resetar, step configurável e validação dos limites mínimo e máximo.

## Como executar a atividade React

```bash
cd tarefa-react
npm install
npm run dev
```

## Como executar a atividade do contador

```bash
cd tarefa-contador
npm install
npm run dev
```
