# Estudos de Sistemas Web

Repositório usado para desenvolvimentos das atividades da disciplina CC6PDSW - Projeto e Desenvolvimento de Sistemas Web.

## Atividades

- `atividade-interface`: páginas desenvolvidas com CSS tradicional e Tailwind CSS.
- `tarefa-javascript`: exercício básico de JavaScript.
- `tarefa-react`: aplicação React com TypeScript, componentes reutilizáveis e três páginas.

## Como executar a atividade React

```bash
cd tarefa-react
npm install
npm run dev
```
